# Arquitetura do Backend

Este diretório contém os arquivos `.drawio` que representam a arquitetura de algumas funcionalidades do backend do projeto. Os diagramas foram criados utilizando a biblioteca Draw.io Integration.

## Estrutura do Diretório

- `feed.drawio`: Diagrama que representa a arquitetura do sistema de feed de dados, detalhando como as diferentes partes do sistema interagem e processam informações.
- `scriptaAPI.drawio`: Diagrama da arquitetura da API Scripta V2, mostrando os fluxos de comunicação entre os serviços e os principais componentes da API.

## Como Visualizar os Diagramas

Para visualizar ou editar os diagramas, é necessário:

1. Usar a extensão Draw.io Integration no editor de código.
2. Ou abrir diretamente os arquivos no [Draw.io](https://app.diagrams.net/).
